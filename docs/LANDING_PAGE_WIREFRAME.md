## Section Details

### 1. Hero Section
**Layout**: 2-column grid (50/50)  
**Background**: Light gray

**Left Column**:
- Badge: "For Employers & Companies"
- H1: "Connect with University Talent" (5xl, bold)
- Subheadline: Description text (xl)
- 2 CTAs:
  - Primary: "View Plans" (large, with arrow)
  - Secondary: "Contact Us" (outline)

**Right Column**:
- Image placeholder (dashed border)
- Square aspect ratio
- Center-aligned placeholder text

**Conversion Focus**: 2 clear CTAs, social proof stats

## Layout Principles

### Desktop-First
- Max width: 1280px (7xl)
- Responsive grid: 2, 3, 4 columns
- Proper spacing (py-20 between sections)

### Visual Hierarchy
1. Large headlines (4xl-5xl)
2. Clear subheadlines (xl)
3. Readable body text (lg-base)
4. Whitespace for breathing room

### Conversion-Focused
- CTAs above the fold
- Multiple CTAs throughout
- Clear value propositions
- Remove friction (free trial)
- Social proof at multiple points

### Section Pattern
Each section follows:
1. Centered title + subtitle
2. Content grid
3. Optional CTA
4. Border separator

## Responsive Behavior (Desktop-First)

### Desktop (>1024px)
- Current layout (optimal)
- Multi-column grids

### Tablet (768-1024px)
- 4-col → 2-col grids
- 3-col → 2-col grids
- Maintain readability

### Mobile (<768px)
- All grids → 1 column
- Hero: Stack vertically
- Reduce padding
- Larger CTAs

## Conversion Flow

```
Landing → Hero CTA → Pricing → Select Plan → Sign Up
        ↓
      Contact Us → Sales Team
```

**Multiple Entry Points**:
1. Hero → View Plans
2. Pricing → Get Started (×3)
3. How It Works → Get Started Now
4. Final CTA → View Pricing Plans

**Exit Prevention**:
- Final CTA before leaving
- "Contact Sales" alternative
- Free trial emphasis
